## 4차 P1 재확인: 개발 서버 데모 새로고침 반복 → 해결

**코드**
- `MainLayout`이 데모 플래그를 `useSyncExternalStore`(서버 스냅샷 false)로 읽습니다. 그래서 하이드레이션 시 서버와 클라이언트 트리가 같습니다.
- 개발용 로그 패널은 `NEXT_PUBLIC_SHOW_DEV_LOGS=true`일 때만 켜집니다.
- `getSnapshot`은 렌더마다 다시 읽으므로, 로그인 후 토큰이 바뀌어 다시 렌더될 때도 값이 맞게 바뀝니다.

**브라우저 확인**
- 환경: 새로 띄운 `fe-mock` 개발 서버, 저장소와 서비스 워커를 비운 상태, 375×812 모바일 뷰포트.

## 참고 (건수에 넣지 않음)
- **MSW 시작 대기**: 스크립트로 빠르게 페이지를 이동하던 중 `/login`이 한 번 빈 화면으로 멈췄습니다.
  - `MSWProvider`의 `worker.start()`가 끝나지 않은 경우로 보입니다. 새로고침하면 바로 정상이었습니다.
  - `MSWProvider`에는 `catch`나 시간 제한이 없습니다. 다만 이번 변경과 무관하고 mock 모드 개발 환경에서만 쓰이는 코드입니다.
- **데모 퀵로그 Notice 문구**: 제목과 본문 첫 문장이 둘 다 "데모 모드 예시 결과예요"라 같은 말이 반복됩니다.
