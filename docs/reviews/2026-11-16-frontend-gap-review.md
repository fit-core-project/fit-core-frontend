# 2026-11-16 프론트엔드 기능 점검 (필요·부족 기능)

방법: 4개 영역 읽기 전용 점검(루틴·운동 / 계정·온보딩·마이 / 식단·영양제·관리자·전체 구조 / BE·AI API 대조). 핵심 주장은 코드로 재확인함(✔).

## P0 — 데이터 손실·막힘

1. ✔ **프로필 부분 저장이 다른 필드를 지움.** BE `UserProfileEntity.updateProfile`이 모든 필드를 요청값으로 덮어씀(null 무시 없음). FE는 일부만 보냄.
   - 온보딩 `StepWorkout.tsx:54` → 닉네임·성별·생년월일 삭제 → 다른 기기에서 온보딩으로 다시 튕김.
   - `ProfileEditForm.tsx:79` → 목표·분할·장비·통증 부위·근력 기준·체성분 이력 전부 삭제.
   - `WorkoutSettingsSection.tsx:218` → 닉네임·체성분 이력 삭제. 데모 모드는 병합해서 버그가 안 보임.
2. ✔ **실제 수행한 무게·횟수가 기록되지 않음.** `ai_routine/player/page.tsx:216` 저장 시 `weightKg: targetWeightKg`, `reps: targetReps`. 플레이어에 입력 칸 없음 → 기록·PR·AI 진행 데이터가 전부 계획값.
3. ✔ **운동 중 토큰 만료 시 기록 유실.** JWT 1시간, 리프레시 없음. 401이면 즉시 `/login` 하드 리다이렉트(`AxiosController.ts:118`) → 저장 실패 화면도 안 뜸. 백업 키(`fitcore_failed_workout_save`)는 아무도 읽지 않고 재로그인 시 삭제됨.
4. **`getMe` 실패 = 강제 로그아웃** (`MyPageContent.tsx:66`). 네트워크 일시 오류에도 로그아웃. 날짜 없는 체성분 1건이 BE 정렬에서 예외를 낼 수 있어 상시 로그아웃 위험(미검증).
5. ✔ **운동이 0개인 AI 루틴 저장 가능 → 플레이어에서 종료 불가** (`routine/draft/page.tsx:316`, 수동 모드만 검사).

## P1 — 중요한 부족

**운동 실행**
- 조기 종료·세트 건너뛰기 저장 불가(모든 세트 체크해야 저장). X는 저장 없이 나감.
- 운동 중 세트 추가/삭제, 운동 교체·순서 변경 불가(기계가 비어도 다음 운동으로 못 넘어감).
- 이어하기 없음: 종료 시트는 "나중에 이어서" 약속, 홈에 재개 진입점 없음. 다른 루틴 시작 시 진행 중 운동을 경고 없이 덮어씀(4곳). 재진입 시 시작 시간 초기화.
- 휴식 종료 알림 없음(진동·소리·알림), 화면 꺼짐 방지(Wake Lock) 없음, +30초 없음, 새로고침 시 타이머 유실.
- 지난번 기록("60kg × 8") 플레이어에 미표시(교체 시에만 조회).
- 체감 난이도 1~3을 `rpe`(1~10 척도)로 저장, `setType`·`isFailure`·`readinessLevel` 하드코딩.
- 단위 설정(lbs)이 플레이어에 미적용(kg 고정).
- 컨디션 체크: 프로필 통증 부위 로드 실패를 숨기고 빈 목록으로 생성 → 보호 부위 미반영(안전).
- 인체 다이어그램: 키보드·스크린리더 불가, 작은 부위 44px 미만, 라이브러리에 없는 부위(side-deltoids) 선택 불가.
- 드래프트: 카탈로그 로드 실패 시 "루틴이 없어요", 교체 실패 시 빈 운동이 저장 가능, 횟수 입력칸을 비울 수 없음(10→1→18).

**계정·온보딩**
- 회원 탈퇴 없음(BE `withdraw()`만 존재, API 없음). 약관·개인정보 처리방침·동의 단계 없음(건강 관련 정보 수집 중).
- 라우트 가드 비활성(`AuthProvider.tsx:56` 주석 처리). 401 시 역할 쿠키 남음.
- 온보딩 완료 판정이 기기 단위·닉네임만 확인, 홈에서만 검사, 뒤로 가기 없음. 통증 부위·체중·분할·주요 리프트 기준 무게 미수집, 키 필드 자체가 없음.
- 체성분 기록 수정·삭제 불가, 입력 검증 약함.
- OAuth 오류·계정 연동 결과 미표시, 토큰이 URL 쿼리로 전달되어 히스토리에 남음.

**식단·영양제**
- 퀵로그: 저장 전 항목별 수정·삭제 불가, kcal 미리보기 없음, 끼니·날짜 선택 없음(항상 오늘).
- `/nutrition`: 수정·삭제 후 오늘 합계·주간·달력이 갱신 안 됨. 수정 시 매크로를 바꿔도 이전 kcal 유지.
- 영양제 상담: 대화 맥락 없음(질문만 전송, FE·BE·AI 모두), 기록 없음(새로고침 시 사라짐).
- AI 요청 타임아웃 500초, 취소 버튼 없음. AI 페이지에서 AI 상태 표시가 숨겨짐.

**전체 구조**
- `error.tsx`·`not-found.tsx`·`global-error.tsx` 없음 → 렌더 오류 시 흰 화면, 영문 기본 404.
- 관리자: 역할 쿠키가 세션 쿠키라 브라우저 재시작 후 관리자도 `/admin`에서 튕김.
- 통계·프로그램·달력: API 실패를 "기록 없음"으로 표시(재시도 없음). 영양 목표 로드 실패 후 저장하면 빈 값으로 덮어씀.

## P2 — 개선

- 운동 후 요약(볼륨·시간·PR·지난번 대비) 없음, 세션·세트 메모 없음, 과거 운동 수정·삭제 없음.
- 영양 목표 달성률 계산 오류(300kcal도 달성), 주간 미터 일할 계산 안 함, 단백질 권장 120g 하드코딩.
- 영양제: "의료 조언이 아님" 문구 누락(PRODUCT.md 제약), 오류 시 원문 메시지 노출·재전송 없음, 주의 블록 좌측 줄(DESIGN.md 위반).
- 오프라인 처리 없음. React Query 탑재만 하고 미사용(수동 refresh key → 갱신 누락의 원인).
- 데모: PR·출석·일별 요약이 빈 배열, 데모 토큰이 ROLE_ADMIN, 운영에서도 데모 로그인 기본 노출.
- `prompt-explain` 페이지(면접 데모용, 영문)가 공개 라우트로 존재. 미사용 코드(`routineRepository`, `fixtures`, `AttendanceSection`, `getUserPainProfile`).
- MSW 청크·`mockServiceWorker.js`가 운영 산출물에 포함(실행은 안 됨), mock 범위가 루틴·운동뿐, 식단·영양제 테스트 없음.
- 미사용 BE 기능: `GET /api/workouts/{id}`(운동 상세), `POST /api/ai/parse-log`(운동 자연어 기록). AI `routine-feedback`은 BE 연결 자체가 없음.

## 우선 처리 제안

1. 프로필 저장 병합(BE에서 null 무시 또는 FE에서 전체 전송) — 데이터 손실
2. 플레이어에서 실제 무게·횟수 입력 + 조기 종료 저장
3. 토큰 만료 대응(리프레시 또는 저장 실패 백업 복구) + `getMe` 실패 시 로그아웃 대신 재시도
4. 빈 루틴 저장 차단, 이어하기·덮어쓰기 경고
5. error/not-found 페이지, 회원 탈퇴·약관
6. 퀵로그 저장 전 편집, 휴식 종료 진동·Wake Lock, 지난번 기록 표시
